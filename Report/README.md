# Technical Simulation & Design Note (PDF)

Complete 6-page IEEE-style technical design note documenting the analytical sizing, 3D full-wave HFSS setup, baseline `50.0 Ω` verification, `Optimetrics` width sweep (`50–1100 µm`), and `2 × 2` electric/magnetic field modal analysis across **60–120 GHz**.

* 📄 **View / Download Full Report:** [`G-CPW_90G.pdf`](G-CPW_90G.pdf)

## Document Contents
* **Cover Page:** 3D trimetric geometry overview and headline `60–120 GHz` performance metrics
* **Section I:** Introduction & physical trade-off between skin-effect loss and higher-order modal cutoff
* **Section II:** Fused-silica stack-up, analytical synthesis, TGV pitch rules, and HFSS boundary setup
* **Section III:** Baseline `50.0 Ω` GCPW verification (`0.185 dB/mm` loss, `−27.43 dB` return loss, `−91.42°` phase at `90 GHz`)
* **Section IV:** `Optimetrics` width sweep results (`Table I-A` & `Table I-B`) and dispersion analysis (`80–235 µm` operating window)
* **Section V:** Full-wave `|E|` and `|H|` field comparison (`W = 119 µm @ 90 GHz` vs. `W = 700 µm @ 120 GHz`)
* **Sections VI & VII:** Feedline design rules for downstream microstrip passive circuits and conclusions
